# Project Skyscraper

This is some stuff I've written to assist with the Project Skyscraper Alternate Reality Game for No Man's Sky.

## Systems Graph
A [plot of systems](https://rinhatayuun.github.io/prj_skyscraper/Systems_Graph.html), derived from the coordinates given by the RecallDreams terminal (EotT demo). The MAIN FAM system has been included for reference, because some people asked for it.

## Systems Graph Neighbours
A [plot of neighbouring systems only](https://rinhatayuun.github.io/prj_skyscraper/Systems_Graph_Neighbours.html), derived from the coordinates given by the RecallDreams terminal (EotT demo). The MAIN FAM system has NOT been included.
